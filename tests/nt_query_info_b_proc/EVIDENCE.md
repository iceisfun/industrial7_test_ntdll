# nt_query_info_b_proc: process, thread, token, job, virtual memory and system information queries

Oracle: Windows 10 22H2 (ntdll 10.0.19041.2788), x64 structure layouts. All exports are syscall stubs
(Nt/Zw share an RVA, asserted by `alias_pairs`), so error ordering and codes are observed results from the
guest. Cross-checks use kernel32 (GetSystemInfo, GetProcessHandleCount, GetProcessTimes,
ProcessIdToSessionId, GetLogicalProcessorInformationEx, GetProductInfo is not used here) as the documented side of
each value.

## Elevation

`token_information` derives its expectation for elevation / integrity level from the same token (elevated
implies integrity >= High) and so passes in both administrator and standard-user runs.
