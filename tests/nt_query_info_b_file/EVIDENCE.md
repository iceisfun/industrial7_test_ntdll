# nt_query_info_b_file: file query services

Oracle: Windows 10 22H2 (ntdll 10.0.19041.2788), x64. The exports are syscall stubs (Nt/Zw share an RVA,
asserted by `alias_pairs`); layouts follow the public `ntddk.h`/`wdm.h` structures and every status code was
observed on the guest. Scratch files live in the per-process temporary directory and are deleted by the tests.
Decompiled kernel evidence: Corpus Explorer `ntoskrnl/IoQueryInformationByName` (see below).

## Skips

* `ea_file` skips (with the creation status) if extended attributes cannot be created on the scratch volume.
