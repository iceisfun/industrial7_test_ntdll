# nt_set_info_b_obj: object, process, thread, token, job, debug-object, symbolic-link and registry setters

Oracle: Windows 10 22H2 x64. Everything is observed on the guest unless a documentation source is named. Objects are
private (duplicated tokens, child processes created suspended and terminated, threads created suspended, volatile
registry keys under HKCU removed at the end, unnamed object directories).

| Export | Expectation |
|---|---|
| NtSetInformationObject | ObjectHandleFlagInformation(4): Inherit and ProtectFromClose round-trip through NtQueryObject and GetHandleInformation; NtClose of a protected handle STATUS_HANDLE_NOT_CLOSABLE (0xC0000235); wrong length INFO_LENGTH_MISMATCH; class 0 and 0x7fff INVALID_INFO_CLASS. NULL and unresolvable handles give STATUS_ACCESS_DENIED (not INVALID_HANDLE) for this class |
| NtSetInformationProcess | priority class (18): IDLE/ABOVE_NORMAL/BELOW_NORMAL observable via GetPriorityClass, 7 STATUS_INVALID_PARAMETER, length 1 INFO_LENGTH_MISMATCH; affinity (21): single CPU observable, 0 and bits outside the system mask STATUS_INVALID_PARAMETER; priority boost (22), default hard-error mode (12) round-trip through NtQueryInformationProcess (GetErrorMode inverts bit 0); bad class INVALID_INFO_CLASS; query-only handle ACCESS_DENIED; thread pseudo handle and event TYPE_MISMATCH |
| NtSetInformationThread | base priority (3) +2/-2/0 observable via GetThreadPriority; affinity (4) and priority boost (14) likewise; 0 affinity INVALID_PARAMETER; ThreadHideFromDebugger (17) takes no data (length 4 INFO_LENGTH_MISMATCH, length 0 sets the flag, query returns a BOOLEAN 1); ThreadNameInformation (38) is read back with GetThreadDescription (an HRESULT_FROM_NT of success has bit 28 set, so the check is `>= 0`); handle errors as above |
| NtSetContextThread | CONTEXT_INTEGER and CONTEXT_FLOATING_POINT (x64) round-trip on a suspended thread; NULL context STATUS_ACCESS_VIOLATION; context not 16-byte aligned STATUS_DATATYPE_MISALIGNMENT (0x80000002); handle without THREAD_SET_CONTEXT ACCESS_DENIED |
| NtSetInformationToken | on a duplicated primary token: TokenOwner (4) set to the token user, an SID that cannot own STATUS_INVALID_OWNER (0xC000005A); TokenPrimaryGroup (5) STATUS_INVALID_PRIMARY_GROUP (0xC000005B); TokenDefaultDacl (6) round-trips (one ACE) and NULL ACL accepted; TokenIntegrityLevel (25) lowered to Low (4096) and read back; TokenVirtualizationEnabled (24) sticks only if TokenVirtualizationAllowed (23) is 1; TokenSessionId (12) STATUS_PRIVILEGE_NOT_HELD; read-only classes (TokenElevation) INVALID_INFO_CLASS; query-only token ACCESS_DENIED |
| NtSetInformationJobObject | basic limit (2), extended limit (9), UI restrictions (4), end-of-job-time (6) set and read back with QueryInformationJobObject; KILL_ON_JOB_CLOSE through the basic class, unknown flag bits and end-of-job action 2 give INVALID_PARAMETER; query-only classes (1) INFO_LENGTH_MISMATCH (size checked first); class 0 and 0x7fff INVALID_INFO_CLASS; QUERY-only handle ACCESS_DENIED |
| NtSetInformationDebugObject | class 1 (KillProcessOnExit) flags 0/1 succeed, flags 2 INVALID_PARAMETER, short length INFO_LENGTH_MISMATCH, ReturnLength is written as 0, classes 0 and 2 STATUS_INVALID_PARAMETER |
| NtSetInformationSymbolicLink | requires SYMBOLIC_LINK_SET (0x2) on the handle: a query-only handle is ACCESS_DENIED before anything else; class 1 (global link flag) STATUS_PRIVILEGE_NOT_HELD; bad class, bad length, NULL handle and wrong type as usual |
| NtSetInformationKey | KeyControlFlags (2) round-trips through NtQueryKey(KeyFlagsInformation); KeyWow64Flags (1) accepts 0 and 1, rejects 0x20/0x100/0x200/0x300 with INVALID_PARAMETER and leaves the value; bad class INVALID_INFO_CLASS; read-only key handle ACCESS_DENIED |
| NtSetValueKey | DWORD/SZ/BINARY/NONE, default value (empty name) and zero-length data round-trip via NtQueryValueKey (KeyValuePartialInformation); names case-insensitive; TitleIndex ignored; NULL name or NULL data pointer STATUS_ACCESS_VIOLATION; a name over 16383 characters STATUS_INVALID_PARAMETER; deleted key STATUS_KEY_DELETED (0xC000017C); read-only key ACCESS_DENIED |

Skips: registry/token/job tests skip if the scratch key, token duplicate or object directory cannot be created.
